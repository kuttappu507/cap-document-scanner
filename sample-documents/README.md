# Sample documents for testing DocScan

All names, numbers and businesses are fictional. Print the PDFs, or open the
`png/` versions on a computer screen and point your phone at it.

| File | Tests |
|---|---|
| `01-receipt.pdf` | Tall, narrow paper with small monospaced text. Print at 100% and scan on a dark surface. |
| `02-invoice.pdf` | A4 page with a colour header and a table; checks perspective correction. |
| `03-rental-agreement-3-pages.pdf` | 3 pages, so use it to test multi-page scans and PDF output. Print all pages. |
| `04-id-card-sample.pdf` | Small card-sized object on a large sheet; cut it out to test edge detection. |
| `05-business-cards.pdf` | Four cards in different colours; scan one at a time or the whole sheet. |
| `06-handwritten-notes.pdf` | Handwriting-style text on ruled paper, for readability and cleanup. |
| `07-application-form.pdf` | Thin lines, boxes and small labels; the form needs to stay crisp. |

`png/` holds a first-page image of each PDF (page 1 only for the agreement).

## Tips
- Scan against a contrasting surface, e.g. white paper on a dark desk.
- Try a slight angle, dim light and a curled page to see perspective correction and clean-up at work.
- In Settings, try Page limit 2 against the 3-page agreement.
